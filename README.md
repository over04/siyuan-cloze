# SiYuan Cloze Plugin (思源局部完形填空)

专注于思源笔记中**选区局部（文字与数学公式）的原地完形填空与背诵遮罩**。

## 🌟 核心特性

- 🎯 **100% 聚焦局部选区**：绝不污染整行段落容器，只对你选中的字词、符号或数学公式（如 `(\boldsymbol{A}^{-1})^{-1} = \boldsymbol{A};` 中的单个 $\boldsymbol{A}$）进行精准挖空。
- 🟡 **纯净荧光黄高光质感**：零下划线、零边框、零外边距，遮挡时文字与 KaTeX 公式完全透明，仅保留黄色高光色块。
- 👆 **点击揭晓（逐块持久）**：点一下任意遮罩块，整簇（含被行内公式夹住的切片）平滑揭晓；再点一下恢复遮蔽。揭晓状态在本次文档打开期间一直有效，切换页签也不丢，关闭文档即回到默认遮蔽——零落盘，不污染笔记数据。
- 👁️ **划选透晓**：遮罩开着时划选，与选区相交的遮罩块临时透晓，让你看清自己选了什么；选区离开立即恢复遮蔽。
- 🌉 **空格无缝桥接**：自动识别公式与汉字之间的裸空格，无缝涂满高光背景，彻底根除白色断裂缝隙。
- ⚡ **一键全局显隐**：快捷键 `⌥X` 或顶栏眼睛图标，一键翻转整篇文档的背诵遮挡总开关。

## 🚀 使用指南

1. **局部标记**：在笔记中选中任意需要背诵的词汇或数学公式，按思源原生高亮（`==`）。
2. **逐块揭晓**：点击任意遮罩块即可揭晓答案，再点一下恢复遮蔽；揭晓状态保留到本次文档关闭。
3. **全局显隐**：按 `⌥X` 或点击顶栏右侧的「眼睛图标」，一键开启/关闭整篇文档的背诵遮挡。
4. **划选透晓**：遮罩开着时划选，选区相交的遮罩块会临时透晓，便于确认选区。
