# SiYuan Cloze Plugin (思源局部完形填空)

专注于思源笔记中选区局部（文字与数学公式）的原地完形填空与背诵遮罩。

## 核心特性

- 🎯 **100% 聚焦局部选区**：只对选中的字词、符号或数学公式挖空，不污染整行段落容器。
- 🌫️ **透明模糊遮蔽**：文字与 KaTeX 公式在遮蔽态统一模糊、灰度化；不改变原有排版与富文本结构。
- 🎨 **行内样式原样保留**：遮罩里套高光、行内代码、加粗、斜体、下划线、删除线、上标、下标、链接、标签、块引用、备注与自定义文字样式，外观与未加遮罩时一致。
- 👆 **点击切换揭晓/遮蔽**：隐藏模式下点一下遮蔽块揭晓整簇，再点一下恢复遮蔽；全局显示模式下内容直接编辑。
- 👁️ **划选透晓**：遮蔽开着时划选，与选区相交的遮罩块临时透晓，选区离开立即恢复。
- 🌉 **零宽字符桥接**：同一次挖空被行内公式切开的切片之间只有零宽字符，插件按簇统一处理；真实空格仍会断成两个遮罩。
- ⚡ **一键全局显隐**：`⌥⇧X` 或顶栏眼睛图标，一键翻转整篇文档的遮挡总开关。
- 📱 **移动端可创建**：桌面选区工具栏与手机键盘工具栏共用同一个挖空按钮。

## 使用指南

1. **局部标记**：选中需要背诵的词汇或数学公式，按 `⇧⌘C`；手机点键盘工具栏的挖空按钮。
2. **逐块切换**：隐藏模式下点击任意遮蔽块揭晓整簇，再点一次恢复遮蔽。
3. **全局显隐**：`⌥⇧X` 或点击顶栏右侧的眼睛图标；切到全局显示模式后，正文可直接编辑。
4. **取消遮罩**：把光标放进遮罩内，或选中遮罩（可多选），再按 `⇧⌘C`。
5. **划选透晓**：遮罩开着时划选，选区相交的遮罩临时透晓。

## 说明

- 需要思源 3.8.3 或更新版本（使用编辑器工具栏插件接口）。
- 插件复用思源行内键盘样式（`kbd`）作为遮罩标记；笔记里已有的键盘样式文本在遮挡开启时也会被遮住。
- 遮罩样式只作用于编辑器正文：其它插件的界面、导出预览与脑图视图里的键盘样式保持原样。
- 遮罩跨过行内公式时，公式可能是与切片平级、自身不带遮罩标记的节点（手写 Markdown 里的 `<kbd>…</kbd>$x$<kbd>…</kbd>`），插件按簇统一遮蔽，答案不会从公式处漏出；紧挨遮罩、位于整簇之外的公式保持原样。
- 揭晓状态只保存在本次文档打开期间，不写入笔记数据；关闭文档后恢复默认遮蔽。
- 默认快捷键可在「设置 → 快捷键 → 插件」中修改。
