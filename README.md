# 思源局部完形填空（SiYuan Cloze）

把笔记中的文字或行内公式遮住，背诵时再点开查看答案。

## 使用方法

1. **创建挖空**：选中文字或公式，按 `⇧⌘C`，或点击编辑器工具栏里的挖空按钮。手机上，这个按钮在键盘工具栏里。
2. **查看答案**：点击一处挖空显示答案，再点一次将它遮住。拖动选中文字时，选中的挖空会暂时显示，取消选中后恢复。
3. **显示所有答案**：按 `⌥⇧X`，或点击顶栏的眼睛图标。显示所有答案后，可以直接编辑正文。
4. **取消挖空**：把光标放在答案里，或选中要取消的挖空，再按 `⇧⌘C`。一次可以取消多处。

## 说明

- 需要思源 3.8.3 或更新版本。快捷键可在「设置 → 快捷键 → 插件」中修改。
- 答案以模糊、灰度的方式遮住。查看时仍会显示内容原有的高亮、加粗、链接等行内样式。
- 一次选中的文字和行内公式会一起遮住、一起显示。如果两处挖空之间留有普通空格，它们会分别显示。
- 在表格里，可以直接选中同一个单元格中的文字或行内公式来创建挖空。单元格里有多个段落时，每个段落中的选中部分会分别挖空。
- 插件使用思源的行内键盘样式（`kbd`）标记挖空。开启遮挡后，正文原有的键盘样式文字也会被遮住。导出预览和脑图保留原样。
- 关闭文档后，逐个点开的答案会恢复为当前的统一显示设置。
